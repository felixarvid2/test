Ferrite for Android 0.1.0

First release of the Android browser, built on Android System WebView (Chromium).

- Tabs, address bar with search, bookmarks, history, downloads, find in page, desktop-site mode.
- Ad and tracker blocking with Brave's adblock-rust, EasyList, EasyPrivacy and uBlock Origin lists and scriptlets (YouTube ads included), per-site exceptions.
- Daily update check against GitHub releases (no silent install).
- No Proton Pass, no extensions.

Install: download `Ferrite-0.1.0.apk` and open it. Android asks once to allow installs from your browser or file manager.
Check the download against `SHA256SUMS`. If you installed an APK from an earlier build signed with a different key, uninstall it first (see README, "Signing").
