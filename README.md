# Projektverkstad

Mina spel, verktyg och experiment samlade på ett ställe. Varje mapp är ett eget projekt med egen README, och projekten är oberoende av varandra.

Repot heter `test`, men fungerar mer som en verkstad: här byggs idéer klart, testas och läggs undan när de inte längre behövs.

## Spel

| Projekt | Vad det är | Kom igång |
|---|---|---|
| [Rune](rune/) | Ett runbaserat roguelike med 150 reliker, mönster och kombinationer. | Öppna `rune/index.html` i webbläsaren. |
| [Tiny Dungeon](tiny-dungeon/) | En pixlig roguelite auto-battler för webben, byggd för YouTube Playables. | `npm install` och `npm run dev` i mappen. |
| [Dungeon Dice Deluxe](Dungeondice.html) | Ett tärningsspel i en enda HTML-fil. | Öppna filen i webbläsaren. |

## Verktyg

| Projekt | Vad det är |
|---|---|
| [Ferrite](browser/) | En skrivbordswebbläsare för Linux, byggd i Rust. |
| [Fartvakt](fartvakt/) | Mäter internethastigheten automatiskt och larmar när nätet avviker. |
| [VLAN-verktyget](vlan-tool-rs/) | Bygger och granskar Cisco-konfigurationer från CSV-filer. |

## Delade resurser

[assets](assets/) innehåller modeller, texturer, ljud, ikoner och annat som flera av projekten använder. Större filer ligger i releasen [Stora assets](https://github.com/felixarvid2/test/releases/tag/assets-large-v1).

## Om projekten

Alla projekt är hobbyprojekt i olika stadier. Några är färdiga och spelbara, andra är prototyper eller verktyg som bara används lokalt. Se respektive README för status, krav och hur du startar just det projektet.
